# Settings publish through Draft/Save, not instantly

Most controls either require an explicit Save (mode, timers) or apply instantly and skip it (Nudge, Confirm, the old opacity slider). Appearance Settings (fonts, colors, Title, Band thresholds) follow the Save path instead of applying instantly: the operator can preview a look on the control window before it reaches the audience popout. This replaces the opacity slider, which was the only prior instant-apply appearance control — so there's no longer a precedent for appearance changes to skip Save.
